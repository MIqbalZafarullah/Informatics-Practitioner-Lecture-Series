# Informatics Practitioner Lecture Series — 6 Studi Kasus

Repositori ini berisi enam implementasi studi kasus Python dan notebook Google Colab (.ipynb) yang disusun berdasarkan materi perkuliahan praktisi industri dan peneliti tamu.

Daftar Studi Kasus:

1. 1-analisis-penjualan-pembayaran
   Analisis Penjualan dan Risiko Keterlambatan Pembayaran.ipynb
   Pemateri: Andria Arisal (BRIN)
   Fokus: Analisis paradoks kenaikan penjualan vs penurunan laba operasional dan pemodelan klasifikasi risiko keterlambatan pembayaran piutang.

2. 2-monte-carlo-sekuensial-paralel
   Estimasi Nilai Pi dengan Monte Carlo Berurutan dan Paralel.ipynb
   Pemateri: Worawan Diaz Carballo (Thammasat University)
   Fokus: Pengujian komputasi sekuensial vs multiprocessing paralel dalam estimasi nilai Pi untuk melihat speedup dan batas efisiensi komputasi.

3. 3-gis-pemilihan-lokasi-gerai
   Pemilihan Lokasi Gerai Sederhana Menggunakan Analisis Spasial.ipynb
   Pemateri: Widi Prima Deva (Citycare Property, Selandia Baru)
   Fokus: Pemilihan lokasi gerai baru di Kota Bengkulu dengan formula jarak Haversine, radius pasar 2 km, dan syarat batas aman kanibalisasi minimal 1 km.

4. 4-klasifikasi-iris-machine-learning
   Klasifikasi Jenis Bunga Iris dengan Machine Learning.ipynb
   Pemateri: Taniza Tajuddin (Universiti Teknologi MARA)
   Fokus: Penerapan pipeline machine learning (StandardScaler + LogisticRegression) untuk klasifikasi tiga spesies bunga Iris serta pencegahan kebocoran data.

5. 5-dashboard-penjualan-user-centered
   Perancangan Dashboard Penjualan Berpusat pada Pengguna.ipynb
   Pemateri: Arafat Febriandirza (BRIN)
   Fokus: Perancangan antarmuka visualisasi data penjualan berbasis prinsip ergonomi kognitif HCI, kartu ringkasan KPI, dan filter interaktif ipywidgets.

6. 6-klasifikasi-gangguan-hutan-sintetis
   Klasifikasi Indikasi Gangguan Hutan dengan Data Sintetis.ipynb
   Pemateri: Dr. Bart Slagter (Wageningen University & Research)
   Fokus: Klasifikasi jenis pemicu langsung deforestasi (pertanian, pertambangan, gangguan alam) menggunakan fitur satelit NDVI dan radar Sentinel-1.

Cara Penggunaan:
Masing-masing notebook dapat langsung diunggah dan dijalankan di Google Colab CPU gratis (Runtime -> Run all).
